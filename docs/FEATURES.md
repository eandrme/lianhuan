# 全功能审阅 · 六档归位

每一个功能都归进六档之一。原则：**能合法再分发而且已经做好的，就直接给完整实现**；
上游明显更完整才诚实推荐；只完成前端的就只说前端；不想要的可以彻底隐藏，但资料不删、以后能恢复。

| 档 | 含义 |
|---|---|
| **①内置** | 装好就在用，不用动手 |
| **②魔改懒人版** | 我们的实现直接给（跟①一样能用），但它学过别人 —— 出处在 UPSTREAM |
| **③指路原仓库** | 想要原作业的去上游装，装配单里有路 |
| **④只要前端** | 界面＋接口契约＋诚实待接，后端自己写 |
| **⑤兼容服务** | 仓内有适配，用户自备合法服务、账号或 key |
| **⑥完全隐藏** | 普通入口全部消失；资料不删、可恢复，也不生成假工作单 |

聊天（流式/分句/思考链/刷新续播）· 记忆（召回注入/总览/分层/增删）· 人设（双方）·
聊天记录按天翻 · 收藏（带上文）· 热力图月历 · 全局搜索 · 藏一句/删一轮 ·
导入导出搬家 · 引擎切换（换个脑子）· 头像上传（中心裁剪）· 返回手势 ·
**想多深（深度思考）**（巢的输入框旁边那枚 🧠：**点一下＝开/关**，开＝偏深、
**关＝真的别想**（会给这家发 `reasoning_effort=none` —— 实测 DeepSeek 不传字段会吐
147 字思考链、传 none 是 0 字，所以「关」不能是「什么都不发」）；
长按（或右键）出四档菜单：别想 / 偏快 / 自动 / 偏深）——
★ 这一档是真接上了的：**一句话进 system**（哪家引擎都吃得到），
OpenAI 兼容那条还会翻成 `reasoning_effort`（fast → 低档、deep → 这家支持的最高一档）。
这家不认那个字段时，从它报错里抄出它认哪几档、**按它认的最高档重来一次** ——
不硬塞、也不让整轮说话失败。之前开源版的 `/api/think` 只写不读，等于摆设。

**每扇对话窗口各两枚开关**（巢的顶栏和「对话窗口」列表里都能拨，默认都开）：

- **主动消息** —— 关掉＝别在这个窗口里主动找我。它只会往「你现在开着的那扇窗」说
  （界面会报一声自己停在哪扇；老前端报不上来时按最后说话的地方猜），
  关掉手上这扇，它就是安静下来，不会绕到别的窗口里去打扰你（闹钟提醒也受这枚管）。
- **离线模式** —— 关掉＝这扇窗名下不给它自己那段时间。

两枚都只是**这一扇窗**的闸；「耳语频率」和服务端 `OFFLINE_ENABLED` 仍是各自的总闸，
两个都开才真的会发生（拨开时界面会直说总闸还关着，不让人以为开关坏了）。
★ 引擎还是回声那种桩（`stub`）时它不会主动开口 —— 回声回的「这是回声引擎……去设置里
挑一个引擎」是给写代码的人看的诊断，不该被当成它想说的话发出去（离线时段同理）。
★ 书房小窗不在其列 —— 那是纯粹的读书助手，走 `book_chat`，跟这套无关。

**巢 › 设置**（原来这格写着「下一批接上」，于是巢里根本没法挑引擎）：

- **大模型引擎** —— 预设（DeepSeek / Kimi / 智谱 / OpenAI / Claude / Ollama…）· 地址 · 模型 ·
  key（不回读明文）→「连接并识别模型」当场问这家有哪些模型 → 点一个就存下并切过去 →
  存完再真连一次确认。认不出来 / 连不上都照实说（428 没 key、502 问不出来，原文摆出来）。
- **主动消息（总闸）** —— 耳语频率 0–100，翻成人话的「一天最多几句」跟后端
  `proactive.daily_max` **同一条公式**（50 那句是 4 不是 5：Python 的 round 是取偶）。
- **离线自由时段** —— 状态（总闸开没开 / 正在不在 / 现在算哪扇窗 / 引擎是不是桩）。
  总闸在 `.env` 的 `OFFLINE_ENABLED`，这一页只读不写，说清楚。
- **推送到手机** —— 网页推送订了几个端 · ntfy 配没配 · 「推一条试试」。
- **空间 · 时间线 · 收藏**（记事里那三档，原项目本来就有的）：
  **空间** —— 贴一条（可配图）/ 戳他发一条 / 楼里接话，分「他发的 · 你发的 · 有评论」，
  帖子和评论都能删。
  **时间线** —— 这个家一天一天怎么起来的：`timeline_events` ＋ meta（天气 / 在哪），
  按 kind 分五条道（装修 / 一起做的事 / 我一个人 / 你的事 / 随手记），
  「几天前」由后端算。
  **收藏** —— 聊天里每条消息的 ⋯ › 收藏这句；收藏带**上文**（「你说：…」）。
  翻历史时收藏过的那句也亮着星（`starred` 一直在 `/api/nest/thread` 里）。
- **助手管理** —— 一位助手下面挂几扇窗，按他分类管所有对话窗口。每位助手自己有：
  头像 · 名字 · 名字下面那行小字 · 系统提示词 · **他能用的 MCP** · 他写的信。
  ★ MCP 是**分人**的：第一位（默认那位）没勾过＝不限（老行为一字不差）；
  新建的助手＝**一个都不给**，要哪个在「管理」里手动勾，别的助手不受影响。
  表筛过还不够，执行那一步再拦一道（防止跑着跑着把 MCP 关了还继续用）。
  主动消息 / 离线自由时段也走同一张表 —— 不然那是静默越权。
  ★ `write_letter` 那只手不知道自己在哪个窗口说话，由执行那一步把当前助手注进去，
  信才分得清是谁写的。没配过助手时这一层整个不出现（老行为）。
- **MCP 工具包（总管理）** —— 加 / 改 / 删 / 拨开关 / 试连，三种连接方式：
  **Streamable HTTP**（一个端点，回包是 JSON 还是 SSE 流都认）、
  **SSE**（老的 HTTP+SSE 短链，`…/sse`）、本机命令（stdio）。
  **自定义请求头**随便加（Bearer token 那种）：只写进 `data/mcp.json`（0600），
  界面只回**名字和末四位**；编辑时那格留空＝沿用已经存着的那把。
  ★ 本机命令（起进程）跟 `/api/mcp/add` 同一条线，**只能在本机页面**加/删/试；
  Streamable HTTP / SSE 不发命令，只是这台机器往外连你填的地址 —— 手机上也能加。

★ 手机那几处硬伤（这一轮排查顺手修的）：
  · `#icons/`、`/manifest.json`、`/sw.js`、`/favicon.ico` 现在**不带 cookie 也给** ——
    iOS「加到主屏」抓 apple-touch-icon 时不一定带 cookie，抓不到就变成一张网页截图。
  · 整屏面板不再盖住底部标签栏（`#pane` 给 `--nest-tabs-h` 让位，进站后重量一次高度），
    标签栏加了 `env(safe-area-inset-bottom)`（iPhone 那条手势条）。
  · 表单控件一律 16px —— 小于 16px 时 iOS 会把**整页**放大，而且不缩回去。
  · 视口跟 `/` 一份不差：`viewport-fit=cover` ＋ `interactive-widget=resizes-content`
    （安卓键盘弹出时缩小可视区，而不是盖住输入框）。

★ `/nest` 的脚本 URL 现在跟 `/` 一样打**内容指纹**（`nest-window.js?v=<md5>`）。
  以前写死 `?v=1`，而 `/sw.js` 对静态资源是缓存优先 —— 改了 nest 的脚本，
  手机上跑的还是几小时前那份，症状是「开关还是两个窗口同步」，跟后端毫无关系。

### Engawa 装不上

安装会在这台电脑上做三件事：建一个独立的运行环境，下载固定版本的 Engawa 和它要的包，跑一遍自检。
没装上时，设置页会把原因和最后几行原话写在按钮底下，先看那一段。常见的几种：

| 看到的 | 怎么办 |
|---|---|
| 没有「安装」按钮，写着这一页不是在那台机器上打开的 | 用手机或别的设备打开连环时会这样：安装只能在跑着连环的那台机器本机上做。连环在家里的电脑上：到那台电脑上，用它自己的浏览器打开（地址以 `localhost` 或 `127.0.0.1` 开头），进「设置 › 功能包」点「安装 Engawa」。连环在自己的云服务器上（不用 Docker、直接跑的）：登录服务器，进连环的文件夹，运行 `python3 scripts/setup-engawa.py`，装好后重启连环。装好以后，手机上也能用 |
| 没有「安装」按钮，写着这里装不了 | 浏览器版（苹果手机只能用这个）、安卓完整体、一键部署到云上（Render / Koyeb）或用 Docker 跑的，都装不了。先把连环装在家里的电脑或自己的云服务器上，再照上一行装 |
| 要 Python 3.11 或更新版本 | 装一个新的 Python，再点一次 |
| 下载没成功（国内网络常见） | 在连环目录里换国内的包镜像装：`PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple python3 scripts/setup-engawa.py` |
| 连不上 GitHub | 先用浏览器下载 `https://github.com/tsuru0805/engawa-mcp/archive/<提交号>.zip`（提交号是 `upstreams/engawa-mcp.lock.json` 里的 `commit`），再运行 `ENGAWA_SOURCE=下载好的压缩包路径 python3 scripts/setup-engawa.py` |
| 电脑上的 git 用不了 | 不用管：没有能用的 git 时，安装器会自动改下同一个版本的压缩包 |

在终端装好之后，重启连环就会接上。

## 玩具箱（🧸 第六格）

他写的小网页都在这儿：`data/plays/*.html` 就是玩具本身（自包含，不引外链）。

- **清单**：`GET /api/plays` 读每个文件的 `<title>` 当名字（没有就退回文件名，只列 `.html`）。
- **玩**：点「玩」在巢里用 `<iframe sandbox="allow-scripts">` 打开。
  ★ 不给 `allow-same-origin` 是**故意的**：小玩意是同一个域名下的网页，
  不隔开它就能伸手摸到外层页面（也就摸得到会话）。代价是它自己的 localStorage 被挡 ——
  要存档 / 联网的小玩意点「新窗口」，在真页面里开。
- **删**：`POST /api/plays/<file>/del`。「他写坏了 / 我不喜欢了」得有地方划掉。
  文件名是外面传进来的：`../` 那种在落盘和删之前就断掉（只收 `xxx.html`）。
- **让他做一个**：`POST /api/plays/new`（真用引擎写，写不出来老实说，不塞空壳上架）。
  它会剥掉 ``` 围栏和解释文字，从 `<title>` 取名字当文件名。

★ 这一轮顺手修了一个**一直是坏的**手：`write_play` / `list_plays` 里的 `_dd`
  被同一个函数里那句 `from datetime import date as _dd` 变成了局部名 → 一调用就
  UnboundLocalError。也就是说他以前想给你写玩具，**每次都是失败的**（界面上只看得到
  「他没做成」）。现在两只手都能用了。

## 外观：和纸墨晕 × 海沫玻璃（⑫ nest-skin.js ＋ nest.html 的 token 层）

一句话氛围：**像在潮湿的宣纸上，落下片会呼吸的海雾。**

- **色彩**：**唯一强调色** `#6E93B3`。正文 `#46505C` / 次要 `#7C8794` / 元信息 `#A7B0BB` /
  墨色 `#6E8296` `#55677C` `#93A6B8`；拉丁小标签另有专用灰 `#8A95A2`。
  **暖土金那一族（上一版的主色）一个字节都不留**；`--warn` 也换成了冷调。
  阴影**只有一种**：`rgba(70,100,130,.10)` —— 纯黑阴影、暖色阴影都没有。
- **底色与墨晕**：和纸 `#F2EDE2`，纸上三层高斯模糊（72px）的青灰 / 水色墨团
  （34s / 40s / 27s 缓慢漂移 alternate），透明度 .15–.30；每团外缘**恰好 3 圈**
  0.5px 内缩的**等高线**（都压到 12%）；顶部一片扇贝边云盖（伞骨细线 + 三道内缩等高线）；
  `feTurbulence` 纸噪铺满，mix-blend overlay **5%**；**8 个** 1–2px 墨点与
  **画出来的**四角星屑（20%、不闪）。
- **材质**：所有卡片 / 导航 / 输入框 / 弹层都是**同一块玻璃** ——
  `rgba(255,255,255,.42)` + `backdrop-filter: blur(18px) saturate(140%)` +
  `1px rgba(255,255,255,.65)` 描边 + 圆角；hover 时轻轻浮起 2px。
  AI 的话＝**墨晕软边**（`rgba(110,130,150,.10)`、圆角 `22/30/26/18`、**无描边**，
  文字直接坐在纸底上）；我的话＝**海沫玻璃**（`rgba(220,234,243,.58)`、
  右下角一个 6px 的指向）。最大宽度 **76%**。
- **排版**：宋体（`Noto Serif SC / Source Han Serif SC / Songti SC` 系统栈，字重 300–500，
  **不引 Google Fonts** —— 那台在手机上常常连不上，而 `<link>` 是阻塞渲染的，
  整页会白等它超时）；**拉丁标签一律 Jost**、全大写、字距 `.24em`、10–13px、
  色 `#8A95A2`；正文 15px / 行高 1.8；**元信息在气泡下方**、10px；
  大数字（陪伴天数）**68px**、accent 色、字重 400；
  分隔一律是 **1px、宽 32–64px、透明度 30%** 的细横线（常与一行字并排）；
  **竖排**（`writing-mode:vertical-rl`）只给空态独白与栏目标签用。
  空窗是**竖排独白** + 一道细线 + 一枚巢标；打字中是三颗**上浮的海沫**（1.6s 循环）。
- **按钮与进度**：按钮一律 **1px 青灰描边**，**选中态 / 主操作才用 accent**；
  不做胶囊墙（分档芯片是 10px 圆角，不是 999px 药丸）；**所有进度条都是 1px 细线填充**，
  没有粗色块。
- **动效**：墨晕 20–40s 漂移；头像 4s 呼吸 `scale 1 → 1.02`；消息入场
  `blur(6px)→0 + translateY(6px)→0`、420ms；玻璃卡 hover 上浮 2px。
  `prefers-reduced-motion` 下**降级成纯淡入**（漂移 / 呼吸 / 上浮 / 位移 / 模糊全停，
  只留透明度的渐显）。
- **书房里「真正的书」那几张卡**：封面是**印章式细线方框**（不是大色块）。
  （上一版那三处微调里，凸起的心和垂线索引都随「撤掉底部导航条」重做进了主界面 ——
   见上面「主界面与五个视图」那一节。）
- **外观面板（`#side` 里那一节）**：预设和颜色挑子都还在，但**默认值就是上面这一套**。
  以前这里的默认是一份**深色**主题（`#0f1115`），而 `apply()` 每次进站都把那些值写进
  `<html>` 的行内样式 —— 行内优先于 `:root`，于是外壳刚画好的和纸、墨晕、海沫玻璃
  全被盖掉。默认值对齐外壳之后，`apply()` 成了一次「写进去也和外壳一样」的空操作。
  预设里那两套暖土金（旧「纸」「暖」）换成了冷调的「月白」「海雾」；
  「气泡圆角 / 小尾巴」两枚滑杆撤了 —— 那两组不对称软边是这套皮的一部分。
- **图标**：`nest-icon.js` 里 67 枚**自绘细线** SVG（24×24、只描边、线宽 1.5、圆头、
  currentColor）。★ **界面里一个 emoji 都没有** —— `test_phone_audit` 里钉了两条：
  可见文本不许出现 emoji 范围字符；每一处 `nestIcon("名字")` 的名字必须在图标表里存在
  （不存在会静默退化成一个小圆点，那种坏法最难查）。
- **深色（月光版）**：`data-moon="1"` 把纸换成夜（`#1C2430`），墨晕与水色整体降亮度；
  抽屉里有「换个月光版 / 回到和纸」，选择记在 localStorage。
  ★ 月亮底下也照样不许用纯黑阴影 —— 跟白天是同一条规矩。
- **六个房间**（顺序是定下的）：**聊天 · 记忆 · 巢 · 书房 · 一起 · 我的**。
  **玩具箱并进「一起」**（不再单独占一格）；「巢」是新的那一格 ——
  一扇窗一张卡，每扇窗的两枚开关（主动消息 / 离线）就在那儿拨。
  ★ **底部导航条已经撤了**（见上一节）：这六格现在是主界面上的卡片与抽屉里那一列；
  左边汉堡拉开抽屉：主界面 + 六个房间 + 新对话 / 窗口 / 搜索 / MCP / 月光，一个入口都不藏。
- **记忆那一格**顶上：**OUR TIDE** 玻璃卡 —— 两个圆头像轻轻交叠、
  **陪伴天数**（68px；从 `/api/chat/heat` 的最早一天真算，没有记录就不显示数字）、
  两人名字、一行斜体诗、`since …`；下面两条小玻璃卡（此刻时间 / 今天），
  ★ 这两块（OUR TIDE ＋ 那排索引）现在是**主界面上的 ③ 和 ④**，
  不再往记忆这一格里塞 —— 见上面「主界面与五个视图」。
- **书房那一格**：书架 / 放书 / 阅读器 / 批注；封面是**印章式的细线方框**，

## 表情包（双方都能发）

- **人**：聊天输入框边上 😀 → 点一张 → 进暂存区（跟发图**同一条路**），配句话发出去。
- **他**：`send_sticker` 那只手，挑哪张看**名字和标签**＋上下文。
  ★ 规矩是硬写进 system 的（含糊一条，模型就会拿一张图替代该说的话）：
  **只用来点缀 · 放在话的末尾 · 不许替代该说的话 · 一轮最多一张 ·
  不是每句都带，挑不到合适的就不发**。
  · 一轮最多一张是**服务端**也拦的（第二张直接不发），不是只写在提示词里。
  · 表里没有的名字**不发**，并把能发的几张报给它 —— 不许在气泡里放个坏图标。
  · 落成那条回复的附件（`files`，`sticker: true`），排在正文**末尾**：
    刷新、换机器、搬家都还在。工具一回来就随 SSE 发出去，不用等刷新。
  · 主动消息 / 离线自由时段那两条路**不摆这只手**（那边的回复没有附件那一栏）——
    答应了却什么都不出现，比不发还糟。

## 一份实测过的「支持 / 不支持」清单

下面这些是**跑出来**的，不是照代码猜的（走查脚本在 `tests/test_attach_and_offline_guards.py`
和四个 jsdom harness 里）。

### 发文件给 AI —— 什么读得到、什么读不到

| | 支不支持 |
|---|---|
| 文字文件（31 种后缀：`txt md csv json yaml py js html css xml …`） | ✅ 内容**原样读出来**塞进这一轮的消息，≤200KB/个、≤400KB/轮（**按字节算**） |
| 图片（jpeg / png / webp / gif） | ✅ 但**只有 OpenAI 兼容那家引擎真的看得见** |
| 图片发给 Claude / 本机 CLI | ❌ 引擎收不到 `Turn.images` —— 旁白会**如实说「我看不见这张图」**，不再骗它 |
| PDF / Word / 压缩包 / epub | ❌ 只存下来 + 给个链接；旁白说「这类这一版读不了，别编」 |
| 超大（图 >8MB、文字 >200KB、一轮 >24MB 图 / 400KB 文字） | ❌ 这一轮不进模型；旁白说「**太大了没读到**」（不再栽赃成 PDF） |
| 一本书（txt，utf-8 / gb18030，≥200 字） | ✅ 走 `/api/books/upload`，切成章存进库（不在磁盘上留文件）；epub 不行 |
| 文件名 | 只有**这一轮**带着；后面几轮只记得「发来过 N 张图、M 个文件」 |
| 张数 | 一轮最多 12 个（界面上限 9 个） |
| 浏览器这一侧 | 图片一律转成 JPEG（长边 1600、q 0.88）—— PNG 透明和 GIF 动图会丢 |

### 工具（AI 的手）
31 只内置 ＋ 用户登记的 MCP。`openai`（API）和 `anthropic`（Claude）**两条引擎都会带上**；
回声（没接模型）和本机 CLI 不带。★ 认 `reasoner` / `deepseek-r1` 那一类**没有 function calling**
的模型时，工具整个关掉 —— 但提示词里那句「你有手」还是会发出去（已知的别扭，未修）。

### 离线（「自己的时间」）
默认 `OFFLINE_ENABLED=0`（关）。开一场要同时满足：静默 ≥ `OFFLINE_IDLE_MIN`、
这一轮离开没跑过、过了冷却/频次、不在夜间静默、当前窗口开着离线、
**引擎不是桩**（这条手动「真跑一场」也不能跳）。那一场里：没有记忆召回、没有聊天历史、
只有名字；做完的话加密存进 `data/private.db`，再按 `OFFLINE_PERMEATE` 渗一点回正常聊天
（关掉总开关就不渗了）。★ `send_sticker` / `write_letter` 在那一场里**当场拒掉** ——
那儿没有回复可挂、也没有助手身份，跑了只会回一句「贴上了」而屏幕上什么都没有。

### 表情包
人来发：✅ 跟普通图片同一条路，真的送到模型眼前（OpenAI 兼容那家）。
AI 来发：✅ `send_sticker` → 随 `tool_done` 事件带出去 → **当场**贴在末尾；
规则是硬的（一轮一张、只在大聊天里发、挑不到就不发、表里没有就把能发的报给它）。
❌ 老的 `/` 那个界面没有表情包（只有 `/nest` 有）。
